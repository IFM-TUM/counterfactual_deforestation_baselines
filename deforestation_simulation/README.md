# README: Profit-oriented reference deforestation simulation (complete 28-country sample and all study periods)

## Description

This R script implements a deforestation modelling approach based on historical profit estimates for alternative land-use/land-cover (LULC) types. Using a parsimonious land-change model, it simulates a reference trajectory of hypothetical deforestation rates over time. Its operating assumption is that land managers allocate land across seven LULC categories based on uncertain profit expectations. It is designed to accompany the manuscript:

> Knoke, T, Cueva, J, Bingham, L, Kindu, M, Döllerer, M, Fibich, J, Köthke, M, Menzel, A, Ramig, A, Senf, C, Biber, P, Wüpper, D, Hänsel, M, Venmans, F, Hanley, N, & Paul, C.   *Measuring the deforestation that didn't happen - a global perspective.* (preprint)

The methodology is based on the approach originally introduced by:

    Knoke, T., Hanley, N., Roman-Cuesta, R. M., Groom, B., Venmans, F., & Paul, C. (2023). Trends in tropical forest loss and the social value of emission reductions. *Nature Sustainability*, doi:10.1038/s41893-023-01175-9  

This repository is designed to facilitate independent replications in the spirit of open science. While the original workflow for the global analysis was carried out using proprietary optimization tools (Frontline Solvers), this script only requires packages that are publicly available at no cost to the user. It can be run for any of the 28 countries discussed in the accompanying manuscript, and reproduces the original results up to random variation in Monte Carlo profit draws.  Country-specific input data and calibrations are supplied in `replication_inputs.rds`, which can be found in this folder. To support reproducibility within the R environment, default seeds are provided in the input tables.

For an example of the original analysis workflow, see the supplementary materials at  https://zenodo.org/records/8016364. For further details, contact the lead author.

## Organization

The script is organized around an iterative simulation workflow with endogenous updating.

1. **Scenarios**: For each Monte Carlo repetition,  1000 uncertainty scenarios are generated by sampling profit coefficients for each LULC type from an uncertainty range around expected values.

2. **Robust optimization**: For each set of scenarios, the script builds and solves a linear programming problem to identify the land-use portfolio that minimizes maximum normalized regret.

3. **Deforestation accounting** : Optimal allocations over a 30-year planning horizon are converted to annual deforestation rates over 5-year operational periods. The implied 5-year change in natural forest share is converted into an annual deforestation rate and an annual forest-loss area. After 5 years, landowners re-asses and update their allocation targets.

4. **Monte Carlo aggregation**: Each simulated year consists of 50 Monte Carlo repetitions. Results are aggregated to produce a mean annual deforestation estimate and associated standard error.

5. **Multi-period updating**: Each period corresponds to five simulated years, after which landowners re-asses their profit expectations and update their allocation targets. Newly deforested land is transferred into existing pasture, and the average LULC composition is used to initialize the next period. 

6. **Baseline correction**: Once the coefficients of variation (CVs) for deforestation and natural forest profits have been calibrated by aligning the modeled deforestation rate with the empirical rate (as measured by earth observation datasets) during the reference period, the remaining mean difference between the observed and simulated deforestation trajectories in the reference period is calculated. That difference is then applied as a constant offset to the remainder of the simulation horizon. Reference and application periods are supplied in input tables for each country.

The optimization balances profit-oriented regret minimization against constraints including:

- Total area constraint (shares sum to one)  
- Forest accounting constraint (natural forest + new deforestation = initial forest area)  
- Land-use capacity limits (e.g. caps on arable and permanent cropland and on pasture)  
- Minimum area requirements for other land uses  
- A prescribed planted forest share 
- Non-negativity  

See the manuscript and its other supplements for further detail.

## System requirements

### Hardware 

The script is intended to run on a standard desktop or laptop. Memory, storage, and execution time depend ont he R installation and computing environment.

### Installation time

Installation time depends on whether R and the required packages are already installed, the machine, and the internet connection. Assuming that the user has R and a common IDE like RStudio already installed, as well as a decent internet connection, package installation typically requires less than five minutes.

### Software 

The  main development environment uses R 5.4.3 (2026.03.11), though backwards compatibility is likely (the script was also tested with R4.2.2(2022-10-31)).

Required R packages (versions we used in parentheses):

- `pacman (0.5.1)`
- `dplyr (1.2.1)`
- `tibble (3.3.1)`
- `ggplot2 (4.0.3)`
- `lpSolve   (5.6.23)` 

We tested the workflow using the following operating systems:

- macOS Tahoe 26.6.2 on Apple Silicon/ARM64
- Windows 11 Pro (64-bit)
- Windows 10 x64 using R 4.2.2

An additional Windows test used `pacman 0.5.1, dplyr 1.0.10, tibble 3.1.8, ggplot2 3.4.0, and lpSolve 5.6.20`. A previous single-country version of the demo script was also tested on macOS Sonoma 14.7.6 (Intel). That version, which can be found in the version history of this repository under the `initial-submission` tag, closely resembles this one. Most of the adjustments to expand the workflow to the full sample involved adjusting input tables and interating over them.

## Inputs

The script requires a single external input file, `replication_inputs.RDS`, which the script assigns to the R object `inputs`.  It contains all data and parameters necessary to run the simulation, including:

  - `periods`: period identifiers, start and end years, and period-specific LULC constraints 
  - `profits`: profit coefficients and uncertainty SDs by country, period, and LULC
  - `initial_areas`: baseline LULC areas used to initialize the first period
  - `annual_series`: Empirical deforestation rates and the manuscript reference scenario
  - `country_settings`: upside/downside multipliers and default random seeds
  - `baseline_corrections`: reference periods for (re-)calibration
 
Make sure that the RDS file is in the same folder as the script, and set that folder as R's working directory (or provide a full file path).

---

## Output

- **Format**: R objects in memory and a plotted figure
- **Location**: Results stored in the R workspace. At the end of the script, there is an option to save the plot as PDF at standard dimensions using `ggsave()`. If desired, uncomment and run this line.
- **Expected runtime**: Less than 3 minutes in a standard computing environment.  

Main objects created:

- `model_df`: annual simulation results for the full simulation period, including  
  - mean annual deforestation rates  
  - standard errors across Monte Carlo repetitions  
  - annual forest loss in 1000 ha  
  - associated year and period identifiers
  - baseline corrections and identifiers  
- `correction_summary`: reference period(s) for (re-)calibration and calculated baseline corrections
- `summary_tbl`: descriptive statistics for each series over the plotting window
-`p`: A ggplot figure showing the simulated profit-oriented baseline deforestation trajectory with uncertainty ribbons and the random seed used.

## Quick start

1. Install R from https://www.r-project.org/ . An IDE like RStudio is also recommended: https://posit.co/downloads
2. Download the folder containing this README, the script `deforestation_demo.R` and the input file `replication_inputs.rds`, or place these files into the same folder.
3. Start a fresh R session and set that folder as the working directory.
4. Open `deforestation_demo.R` in your IDE
5. Below the header (roughly line 44), select the country to replicate:

      `COUNTRY <- "Brazil"` 

6. After assigning your chosen country to `COUNTRY`, select the entire script and run it. Alternatively, you can run it from theconsole with the command:

   `source("deforestation_demo.R", encoding = "UTF-8")`

The script will execute the simulation and plot the simulated deforestation trajectory. 

To test another country, change the value of `COUNTRY` and repeat steps 3-6. To avoid typos, we suggest pasting the country name with quotations from the commented-out list immediately below the `COUNTRY` assignment line. 

Note that the script can run using packages already installed in the user's library (the `pacman` block only installs missing packages; note that it does not enforce package versions). Thus, after the initial run, selecting and running the entire script will not repeat the installation step. 

---

## Reproducibility

We supply default random seeds by country for the Monte Carlo draws in `replication_inputs.rds`. If you modify the script to use a different random seed, we suggest assigning it to `master_seed_used`, so that the graphing block reports the correct seed in the figure subtitle.
