# README: Profit-oriented reference deforestation simulation (complete 28-country sample and all study periods)

## Description

This R script implements a deforestation modelling approach based on historical profit estimates for alternative land-use/land-cover (LULC) types. It simulates a reference trajectory of hypothetical deforestation rates across multiple periods by assuming that land managers allocate land across seven LULC categories based on uncertain profit expectations. It is designed to accompany the manuscript:

> Knoke, T, Cueva, J, Bingham, L, Kindu, M, Döllerer, M, Fibich, J, Köthke, M, Menzel, A, Ramig, A, Senf, C, Biber, P, Wüpper, D, Hänsel, M, Venmans, F, Hanley, N, & Paul, C.   *Measuring the deforestation that didn't happen - a global perspective.* (preprint)

The methodology is based on the approach originally introduced by:

    Knoke, T., Hanley, N., Roman-Cuesta, R. M., Groom, B., Venmans, F., & Paul, C. (2023). Trends in tropical forest loss and the social value of emission reductions. *Nature Sustainability*, doi:10.1038/s41893-023-01175-9  

The original workflow for the global analysis was carried out in Excel using proprietary optimization tools from Frontline Solvers. This script was developed to facilitate replications in the spirit of open science. It only requires packages that are publicly available at no cost to the user, and replicates the original results up to random variation in Monte Carlo profit draws. For reproducibility within the R environment, default seeds are provided in the input tables. For an example of the original analysis workflow, see the supplementary materials published at  https://zenodo.org/records/8016364; for further details, contact the lead author.

The script can be run for any of the 28 countries studied in the accompanying manuscript, and country-specific inputs and calibrations are supplied in the accompanying data file: replication_inputs.rds

## Organization

The script is organized around an iterative simulation workflow with endogenous updating.

1. **Scenarios**: For each Monte Carlo repetition,  1000 uncertainty scenarios are generated by sampling profit coefficients for each LULC type from an uncertainty range around expected values.

2. **Robust optimization**: For each set of scenarios, it builds and solves a linear programming problem to identify the land-use portfolio that minimizes maximum normalized regret.

3. **Deforestation accounting** : Optimal allocations over a 30-year planning horizon are converted to annual deforestation rates over 5-year operational periods. The implied 5-year change in natural forest share is converted into an annual deforestation rate and an annual forest-loss area.

4. **Monte Carlo aggregation** : Each simulated year consists of 50 Monte Carlo repetitions. Results are aggregated to produce a mean annual deforestation estimate and associated standard error.

5. **Multi-period updating** : A period corresponds to five simulated years. At the end of each period, the average LULC composition  is used to initialize the following one. Newly deforested land is transferred into existing pasture before the next period begins.

6. **Baseline correction**: Once the coefficients of variation (CVs) for deforestation and natural forest profits have been calibrated by aligning the modeled deforestation rate with the empirical rate during the reference period as measured by earth observation datasets, the remaining mean difference between the observed and simulated deforestation trajectories in the reference period is calculated, and that difference is applied as a constant offset to the remaining years. Reference and application periods are supplied in input tables for each country (see manuscript and it supplements for details).

The optimisation balances profit-oriented regret minimisation against constraints including:

- Total area constraint (shares sum to one)  
- Forest accounting constraint (natural forest + new deforestation = initial forest area)  
- Land-use capacity limits (e.g. caps on arable and permanent cropland and on pasture)  
- Minimum area requirements for other land uses  
- A prescribed planted forest share 
- Non-negativity  

See the Methods section of the manuscript for further detail

## System requirements

### Installation time
Installation time depends on whether R and the required packages are already installed, the machine, and the internet connection. Assuming that the user has R and a common IDE like RStudio already installed, package installation typically requires less than five minutes.

### Software dependencies

Required software:
- The  main development environment uses R 5.4.3 (2026.03.11), though backwards compatibility is likely (the script was also tested with R4.2.2(2022-10-31)).

Required R packages (versions we used in the main development environment in parentheses):

- `pacman (0.5.1)`
- `dplyr (1.2.1)`
- `tibble (3.3.1)`
-`ggplot2 (4.0.3)`
- `lpSolve   (5.6.23)` 

### Operating systems

Tested on:
- macOS Tahoe 26.6.2 on Apple Silicon/ARM64
- Windows 11 Pro (64-bit)
- Windows 10 x64 using R 4.2.2

An additional Windows test used `pacman 0.5.1, dplyr 1.0.10, tibble 3.1.8, ggplot2 3.4.0, and lpSolve 5.6.20`. A previous single-country version of the demo script was also tested on macOS Sonoma 14.7.6 (Intel). That version closely resembles this one; most of the adjustments to expand to the full sample involved adjusting input tables.

### Hardware requirements

The script is intended to run on a standard desktop or laptop. Memory, storage, and execution time depend ont he R installation and computing environment.

## Inputs

- The script requires a single external input file, replication_inputs.RDS, loaded into the object "inputs".  
- This file contains all parameters necessary to run the simulation, including:

  - `periods`: period identifiers, start and end years, and period-specific LULC constraints 
  - `profits`: profit coefficients and uncertainty SDs by country, period, and LULC
  - `initial_areas`: baseline LULC areas used to initialise the first period
  - `annual_series`: observed deforestation and manuscript baseline
  - `country_settings`: upside/downside multipliers and default random seeds
  - `baseline_corrections`: reference periods for (re)calibration
 
- Place the RDS file in the same directory as the script and set it as the working directory or provide a full file path.

---

## Output

- **Format**: R objects in memory and a plotted figure
- **Location**: Results stored in the R workspace  
- **Expected runtime**: Less than 3 minutes on standard hardware  

Main objects created:

- `model_df`: annual simulation results for the full multi-period run, including  
  - mean annual deforestation rates  
  - standard errors across Monte Carlo repetitions  
  - annual forest loss in 1000 ha and ha  
  - associated year and period identifiers
  - baseline corrections and identifiers  
- `correction_summary`: reference period(s) for (re)calibration and calculated baseline corrections
- `summary_tbl`: descriptive statistics for each series over the plotting window
-`p`: A ggplot figure showing the simulated profit-oriented baseline deforestation trajectory with uncertainty ribbons and the random seed used.

## Quick start demo

1. Install R from https://www.r-project.org/ . An IDE like RStudio is also recommended: https://posit.co/downloads
2. Download the script file and the required .rds input file into the same folder.
3. Start a fresh R session and set that folder as the working directory.
4. Open `deforestation_demo.R` in R or RStudio.
5. Below the header (roughly line 44), select the country to replicate:

      `COUNTRY <- "Brazil"` 

6. Select the entire script and run it. Alternatively, paste the following line into the console and run it:

   `source("deforestation_demo.R", encoding = "UTF-8")`

The script will execute the full simulation for the selected country and display the figure with the simulated deforestation trajectory. To test another country, change the value of `COUNTRY` and repeat steps 3-6. To avoid typos, we suggest pasting the country name with quotations from the commented-out list immediately below the `COUNTRY` assignment line. 

Note that the script can run using packages already installed in the user's library, if applicable. The `pacman` block only installs missing packages. Thus, after the initial run, selecting and running the entire script will not repeat the installation step.


---

## Reproducibility

We supply default random seeds by country for the Monte Carlo draws in `replication_inputs.rds`. If you choose to modify the script to use a different random seed, we suggest assigning it to the variable `master_seed_used`, so that the graphing block reports the correct seed in the figure subtitle.
